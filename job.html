Career Opportunities at WebEXE

WebEXE is looking for motivated and creative individuals who are passionate about web development. Explore our available positions and qualifications.

Trainee Web Developer

Job Description

Work alongside experienced developers to learn how to design, develop and maintain websites.

Responsibilities

  • Assist with creating and maintaining websites.
  • Develop skills in HTML, CSS and JavaScript.
  • Help identify and fix website errors.
  • Participate in team meetings.
  • Learn responsive website development.

Required Qualifications

  • BTEC Level 3 IT or equivalent preferred.
  • Basic understanding of HTML and CSS.
  • Interest in learning JavaScript.
  • Good communication and teamwork skills.
  • Willingness to learn new technologies.

Junior Web Developer

Job Description

Develop and maintain websites, implement new features and work with other members of the development team.

Responsibilities

  • Develop responsive websites.
  • Write HTML, CSS and JavaScript.
  • Test websites for errors.
  • Work with designers to implement layouts.
  • Improve website usability.

Required Qualifications

  • BTEC Level 3 IT or equivalent qualification.
  • Experience with HTML and CSS.
  • Knowledge of JavaScript.
  • Understanding of responsive design.
  • Good problem-solving skills.
